# my-luck-life

Бортжурнал Mercedes-Benz 200E W124 (1991, M102, АКПП 722.4).

Источник правды — git. Телефон пишет заправки, пробег и заметки; с компьютера
в тот же репозиторий дописывается разбор узлов и расхода.

## Данные

- `data/w124/state.json` — машина, пробег, заправки, узлы ТО, записи журнала
- `data/w124/analytics.md` — текстовый разбор (его пишет агент)
- `tools/fuel_report.py` — пересчитывает блок расхода в `analytics.md`

Расход считается от полной заправки до полной. Частичные доливки входят в сумму
литров, но не открывают новый интервал. Тип поездки (город / трасса / смешанный /
короткие) нужен, чтобы отличать стиль езды от роста прожорливости мотора.

Ориентир для этого мотора: 10–12 л/100 км смешанный, 12–14 город.

## Android

Проект: `android/` (Kotlin, Jetpack Compose, minSdk 26).

```bash
cd android
./gradlew :core:test :app:assembleDebug
```

APK: `android/app/build/outputs/apk/debug/app-debug.apk`

После пуша тот же APK собирает GitHub Actions (артефакт `bortzhurnal-debug`).
Ставится как обычное debug-приложение, без Play Store.

### Синхронизация

В настройках приложения — GitHub Personal Access Token с правом Contents
(read/write) на этот репозиторий. Ветка по умолчанию `master`. Без токена
журнал живёт только на телефоне.

## Что умеет приложение

- строка расхода л/100 км и линия тренда
- заправки (литры, пробег, полный бак / долив, тип поездки)
- бортжурнал
- узлы и регламент ТО с напоминанием
- локальные уведомления, если срок узла близко
- синхронизация `state.json` / `analytics.md` с git
