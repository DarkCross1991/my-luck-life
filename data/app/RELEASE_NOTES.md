# 0.5.0

- Главная — рабочий стол: форма записи сразу на экране, заправки и срочные работы там же.
- Поля записи: «Пробег на момент записи», «Описание», «Разбор проблематики от тебя». Без заголовка и тегов.
- Вкладка «Топливо» убрана. Заправка — кнопка на главной, история заправок тоже на главной.
- Журнал показывает те же три смысла: пробег, описание, разбор. Плюс открывает ту же форму.

# 0.4.0

- Починено обновление: постоянная подпись APK и установщик PackageInstaller.
- Первый переход на 0.4.0: синхронизировать, удалить старое приложение, поставить APK с GitHub Releases (старые CI-сборки были с разными ключами).
- Кнопка «Запись» на главной: пробег + текст. Разбор из git появляется третьим полем и во вкладке Журнал.
- Очередь разбора: `data/w124/inbox.json`. GitHub Action пингует PR/issue, когда есть pending.

# 0.3.0

- Срочные работы на главной стали кликабельными: что сделать, сколько висит, срочность, инструмент (зелёный/красный), шаги по порядку.
- Чеклист недостающего инструмента по текущим задачам. Галочка «есть» пишется в git.
- Каталог инструмента: `data/w124/tools.json`. Планы работ: `data/w124/jobs.json`.
